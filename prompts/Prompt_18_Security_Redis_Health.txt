PROMPT 18 — SECURITY, REDIS AND HEALTH CHECKS

Harden the application for production.

Security:
- Helmet
- CORS
- rate limiting
- JWT security
- bcrypt
- input validation
- request size limits
- safe error responses
- no stack traces in production
- no secrets in logs
- AI keys backend-only
- customer data isolation
- admin authorization
- audit logging
- API versioning

Redis-ready features:
- rate limiting
- context caching
- temporary state
- provider health
- background jobs

Redis must not be mandatory for basic MySQL functionality.

Health endpoints:
GET /health
GET /health/database
GET /health/redis
GET /health/ai

Add provider timeout and retry handling.

Review the entire backend for:
- SQL injection risks
- authorization bypass
- IDOR
- mass assignment
- insecure secrets
- unsafe logging
- missing validation
- missing ownership checks

Fix all discovered issues and add tests.
