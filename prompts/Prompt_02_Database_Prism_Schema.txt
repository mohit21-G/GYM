PROMPT 02 — DATABASE AND PRISMA SCHEMA

Implement the complete Prisma/MySQL database foundation.

Use environment-driven database configuration.

Local development:
DB_HOST=localhost
DB_PORT=3306
DB_USERNAME=root
DB_PASSWORD=123456
DB_DATABASE=google-Fitness-ai-chatbot

DATABASE_URL must be generated from environment variables and never hard-coded in source.

Create these models:
- users
- user_profiles
- chat_sessions
- chat_messages
- food_categories
- foods
- food_logs
- activity_categories
- activities
- activity_logs
- weight_logs
- sleep_logs
- hydration_logs
- ai_usage_logs
- admin_audit_logs

Users:
- id
- name
- username
- email
- password_hash
- role
- status
- timezone
- preferred_language
- last_login_at
- created_at
- updated_at

Roles:
CUSTOMER, ADMIN

Statuses:
ACTIVE, INACTIVE, SUSPENDED

Add proper relations, indexes, unique constraints, timestamps and cascading rules.

Food master must store nutrition values.
Food logs must store historical nutrition snapshots.

Activities must support MET values.
Activity logs must store calculated calories burned.

Add Prisma migrations and seed structure.

Seed:
- food categories
- common foods
- activity categories
- common activities
- default admin using environment variables only

Never place admin passwords in source code.

Run Prisma validation, migration and generation and fix all schema errors.
