PROMPT 03 — AUTHENTICATION AND RBAC

Implement complete authentication and authorization.

Customer authentication:
POST /api/v1/auth/register
POST /api/v1/auth/login
POST /api/v1/auth/refresh
POST /api/v1/auth/logout
GET /api/v1/auth/me

Admin authentication:
POST /api/v1/admin/auth/login
POST /api/v1/admin/auth/refresh
POST /api/v1/admin/auth/logout
GET /api/v1/admin/auth/me

Requirements:
1. bcrypt password hashing.
2. JWT access and refresh tokens.
3. Refresh-token rotation/revocation.
4. Auth Guards.
5. RolesGuard.
6. CUSTOMER and ADMIN roles.
7. ACTIVE, INACTIVE and SUSPENDED status handling.
8. Protected customer routes.
9. Protected admin routes.
10. Customer must be logged in before using chatbot.
11. Customer identity must come from JWT, never from user_id submitted by frontend.
12. Customers can only access their own data.
13. Admin can access authorized administration features.
14. Admin cannot access customer passwords.
15. Admin must not impersonate customers.
16. Add safe validation and production-safe errors.
17. Add Swagger documentation.

Use .env:
JWT_SECRET
JWT_REFRESH_SECRET
JWT_ACCESS_EXPIRES_IN
JWT_REFRESH_EXPIRES_IN

Test all authentication flows and fix errors.
