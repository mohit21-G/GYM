PROMPT 12 — CHAT ORCHESTRATION AND CHAT API

Implement:
POST /api/v1/chat/message

Customer must be authenticated.

Frontend request:
{
  "sessionId": "optional",
  "message": "Aaje 30 minute walk kari"
}

Do not trust user_id from frontend.

Flow:
1. Authenticate customer.
2. Validate message.
3. Load relevant context.
4. Call selected AI provider.
5. Validate normalized AI output.
6. Route intent.
7. Resolve master data.
8. Validate business rules.
9. Execute database operation.
10. Store chat messages.
11. Record AI usage.
12. Return structured response.

Response:
{
  "success": true,
  "message": "...",
  "data": {},
  "ui": {
    "type": "LOG_RESULT",
    "cards": []
  }
}

UI types:
TEXT
LOG_RESULT
LOG_LIST
SUMMARY
CLARIFICATION
CONFIRMATION
ERROR
SUGGESTION

Error:
{
  "success": false,
  "message": "...",
  "error": {
    "code": "...",
    "details": {}
  }
}

Handle clarification questions and follow-up context.
Add provider failure handling and safe fallback messages.
