PROMPT 19 — DOCKER AND DEPLOYMENT

Complete Docker and deployment configuration.

Services:
- frontend
- backend
- mysql
- redis
- nginx

Ports must be environment-driven:
BACKEND_PORT=3000
FRONTEND_PORT=5173
MYSQL_PORT=3306
REDIS_PORT=6379
NGINX_HTTP_PORT=80
NGINX_HTTPS_PORT=443

Important:
Local DB:
DB_HOST=localhost

Inside Docker:
DB_HOST=mysql

Do not hard-code localhost for backend-to-MySQL communication inside Docker.

Create:
- Dockerfiles
- docker-compose.yml
- nginx configuration
- environment examples
- production configuration guidance
- health checks
- restart policies where appropriate

Frontend should use:
VITE_API_BASE_URL

Backend must expose its configured PORT.

Document:
- local setup
- Docker setup
- production deployment
- environment variables
- database migration
- Prisma generation
- seed process
- logs
- troubleshooting

Verify a clean Docker build.
