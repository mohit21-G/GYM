PROMPT 01 — PROJECT FOUNDATION

Build the initial foundation for the Google Fitbit AI Chatbot project.

Repository:
google-fitbit-ai-chatbot/
├── frontend/
├── backend/
├── docs/
├── docker-compose.yml
└── README.md

Stack:
- Frontend: React + TypeScript + Vite + React Router + Zustand + Axios + Tailwind CSS
- Backend: Node.js + NestJS + TypeScript + Prisma + MySQL
- Redis-ready architecture
- JWT authentication
- Swagger/OpenAPI
- class-validator
- Helmet
- rate limiting

Requirements:
1. Create frontend and backend applications with clean production-ready structure.
2. Configure TypeScript, ESLint and formatting.
3. Add environment-driven configuration.
4. Never hard-code ports, database credentials, API keys or secrets.
5. Create .env.example.
6. Create README with setup instructions.
7. Create docs/architecture.md documenting the architecture.
8. Add health endpoint structure.
9. Prepare Docker Compose for frontend, backend, MySQL, Redis and Nginx.
10. Keep the implementation modular so AI providers can be switched later.

Do not implement business features yet. Finish the foundation, verify that both applications start successfully, and fix build/type errors.
