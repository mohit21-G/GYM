PROMPT 04 — BACKEND MODULES AND CORE APIs

Create NestJS modules and REST APIs for:
- users
- food
- activity
- weight
- sleep
- hydration
- logs
- dashboard

Customer CRUD APIs:

Food:
POST /api/v1/food-logs
GET /api/v1/food-logs
GET /api/v1/food-logs/:id
PATCH /api/v1/food-logs/:id
DELETE /api/v1/food-logs/:id

Activity:
POST /api/v1/activity-logs
GET /api/v1/activity-logs
GET /api/v1/activity-logs/:id
PATCH /api/v1/activity-logs/:id
DELETE /api/v1/activity-logs/:id

Create equivalent CRUD APIs for weight, sleep and hydration.

Requirements:
- DTO validation with class-validator.
- Customer ownership enforcement.
- Pagination.
- Filtering by date.
- Sorting.
- Proper HTTP status codes.
- Standard response format.
- No direct Prisma access from controllers.
- Controllers → services → Prisma.
- No frontend business logic.
- Swagger documentation.

Create reusable common response and pagination utilities.
